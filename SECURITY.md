# Security reporting

Do not post API keys, private conversations, player identifiers, configuration dumps or operational addresses in a public issue. Use [GitHub's private vulnerability reporting](https://github.com/Chen-Zz1/mc-ai-assistant-mod/security/advisories/new) if enabled. If unavailable, open a content-free request for a private reporting channel; provide sensitive details only after a channel is arranged.

For an exposed key, revoke/rotate it at the provider and review usage; removing it from the latest source file does not erase history or copies. Maintainers should audit source, history, release artifacts and issue attachments before publication. This beta has automated tests and a scoped release-data audit, not an independent security certification.
