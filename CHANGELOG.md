# Changelog

## 0.2.0-beta.1 — prerelease candidate

- Server-side ordinary/multi-turn AI chat, public/private replies and persistent player defaults.
- Generic V1/V2 persona cards with fictional examples; no real-person dataset included.
- Optional Firecrawl search and experimental Wiki retrieval, cache and bounded fallback.
- Cooldowns, concurrency limits, outbound budgets and operator controls.
- Public defaults disable complete conversation audit logging. A first-use notice describes external data flow and current logging settings.
- Pinned build tools, MIT license, third-party notices, configuration/privacy documentation and CI preparation.

Intended for prerelease testing. The initial source import passed local checks and GitHub Linux CI. A fresh two-player in-game acceptance session is pending; see `docs/RELEASE_CHECKLIST.md`.
