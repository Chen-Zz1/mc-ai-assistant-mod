# AI development disclosure

This project was developed through extensive AI coding-agent assistance. A substantial amount of the implementation, tests and documentation was generated or revised by AI from maintainer requirements. The maintainer directed feature choices and testing; those activities do not turn AI-generated code into exclusively human-authored code.

The mod also calls AI models at runtime through operator-configured providers. Runtime model behavior, data handling and costs are separate from how the software was developed. The mod's responses are visibly labeled as AI.

No generated screenshots or fabricated gameplay demonstrations are included. Do not describe this project as entirely human-written or omit this disclosure when a distribution platform requires it. Each platform may set stricter eligibility rules, so publication must be reviewed separately.
